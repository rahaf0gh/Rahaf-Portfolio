# Rahaf Portfolio

Bilingual Arabic/English static portfolio.

Upload these files and folders directly to the repository root. index.html must be at the root, beside assets/ and blog/. No build or npm installation required.

Main files: index.html, style.css, app.js, navigation.js, blog-language.js.
Open index.html locally or serve the folder using a static web server.

The TikTok profile link is awaiting the account URL.
